개인정보 처리방침

StudyPlan  ·  시행일: 2026년 5월 17일

이 앱은 외부 서버나 추적 SDK를 사용하지 않습니다.
사용자의 데이터는 사용자 본인의 기기와 iCloud에만 저장됩니다.

1. 기본 원칙

StudyPlan은 공부 일정 관리에 꼭 필요한 정보만 다루며, 수집한 어떤 데이터도 개발자나 제3자가 읽거나 활용하지 않습니다.

2. 수집·저장하는 정보

2.1 공부 일정 데이터

앱에 입력하는 공부 일정, 완료 기록, 알림 설정은 사용자 본인의 iCloud (Apple CloudKit 비공개 데이터베이스)에 저장됩니다.

  • 개발자(앱 운영자)는 이 데이터에 접근할 수 없습니다.
  • 같은 iCloud 계정으로 로그인된 여러 기기 사이에서만 자동 동기화됩니다.
  • 타인이나 제3자와 공유되지 않습니다.

2.2 캐릭터 이미지 (사진 라이브러리 접근)

사진에서 캐릭터 이미지를 직접 등록할 경우:

  • 선택한 이미지는 이 기기 내의 앱 전용 저장 공간에만 저장됩니다.
  • 이미지 파일은 외부 서버나 개발자에게 전송되지 않습니다.
  • 기기를 바꾸거나 앱을 삭제하면 커스텀 이미지는 사라질 수 있습니다. (iCloud 동기화 대상이 아닙니다.)
  • 사진 라이브러리 접근을 허용하지 않아도 기본 캐릭터 팩을 사용할 수 있습니다.

2.3 알림

이 앱의 알림(아침 요약, 일정 시작 10분 전 알림)은 모두 기기 내 로컬 알림입니다.

  • 외부 서버나 푸시 알림 서비스로 데이터가 전송되지 않습니다.
  • 알림 전송 기록은 어디에도 저장되지 않습니다.

3. 수집하지 않는 정보

이 앱은 다음 정보를 일절 수집하거나 저장하지 않습니다:

  • 이름, 이메일, 전화번호 등 신원 정보
  • 위치 정보
  • 기기 식별자, 광고 ID
  • 사용 패턴, 행동 분석 데이터 (애널리틱스 없음)
  • 회원 가입 정보 (이 앱은 계정 시스템이 없습니다)

4. 제3자 공유

이 앱은 어떠한 정보도 제3자에게 판매·제공·공유하지 않습니다.
외부 광고 네트워크, 분석 SDK, 소셜 미디어 연동 기능이 없습니다.

5. 미성년자 개인정보 보호

이 앱은 만 13세 이상 ~ 18세 이하 중·고등학생을 주 사용자로 합니다.

  • 앱 자체에서 개인정보를 수집하지 않습니다.
  • 공부 일정 등 앱 데이터는 사용자 본인의 iCloud에만 저장됩니다.
  • 부모 또는 법정 대리인이 데이터 삭제를 원할 경우, 기기에서 앱을 삭제하거나 iCloud 설정에서 앱 데이터를 삭제할 수 있습니다.

6. 데이터 삭제 방법

데이터 종류삭제 방법
공부 일정 / 설정 앱 내에서 직접 삭제하거나, 앱을 삭제하면 iCloud에서도 제거됩니다
캐릭터 이미지 앱 → 설정 → 캐릭터 → 캐릭터 없애기
iCloud 앱 데이터 전체 iPhone 설정 → [사용자 이름] → iCloud → 저장 공간 관리 → StudyPlan → 삭제

이 방침이 변경될 경우 앱 업데이트 또는 App Store 업데이트 노트를 통해 안내합니다.
